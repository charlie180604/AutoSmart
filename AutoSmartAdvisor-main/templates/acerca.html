Acerca de AutoSmart Advisor

AutoSmart Advisor es un sistema web inteligente diseñado para apoyar la toma de decisiones en la compra de automóviles mediante el análisis del perfil del usuario, características de vehículos y evaluación de posibles riesgos.

Objetivo del sistema

El objetivo del sistema es recomendar automóviles que se adapten al presupuesto, necesidades de uso y preferencias del usuario. Además, busca advertir cuando una decisión de compra pueda representar un riesgo económico o funcional.

Problema que atiende

Muchas personas compran vehículos sin analizar aspectos importantes como el precio, consumo de combustible, mantenimiento, forma de pago o compatibilidad con su uso diario. Esto puede generar gastos innecesarios o decisiones poco convenientes.

Algoritmos utilizados

El sistema integra diferentes técnicas de Machine Learning para analizar al usuario, generar recomendaciones y evaluar riesgos.

DBSCAN

Se utiliza para agrupar usuarios con características similares, permitiendo identificar perfiles de compra y necesidades parecidas.

Red neuronal

Analiza los datos del usuario y las características de los vehículos para generar recomendaciones con mayor nivel de compatibilidad.

Isolation Forest

Detecta decisiones de compra anómalas o riesgosas, como elegir un automóvil demasiado costoso o poco adecuado para el uso del usuario.

Datasets utilizados

El sistema se apoya en datasets de vehículos para obtener información como precio, modelo, año, combustible, transmisión, kilometraje y otras características relevantes.

Comprehensive Vehicle Specifications Dataset

Contiene especificaciones técnicas de vehículos, útiles para analizar características generales, rendimiento y datos del automóvil.

Vehicle Dataset from CarDekho

Contiene información de vehículos usados, como precio de venta, año, kilometraje, tipo de combustible, transmisión y propietarios anteriores.

Alcance del sistema

AutoSmart Advisor funciona como una herramienta de apoyo para la toma de decisiones. Sus recomendaciones no sustituyen una evaluación financiera profesional ni una revisión técnica del vehículo, pero ayudan al usuario a comparar opciones de manera más informada.
